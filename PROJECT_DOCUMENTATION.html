🚀 2. Project Overview & Problem Statement

Mathematics education often suffers from high student dropouts due to lack of personalized, step-by-step guidance. AI Maths Tutor addresses this by pairing state-of-the-art Large Language Models (LLMs) with strict Retrieval-Augmented Generation (RAG) over the official NCERT syllabus. The result is a hallucination-free, interactive learning partner accessible on any desktop or smartphone.

✨ 3. Core System Capabilities

🧠 Multi-Model Engine with Failover

Powered by Groq Cloud LPUs with models: GPT-OSS 120B (Deep Reasoning), Qwen 3.8 27B (Math Specialist), and GPT-OSS 20B (Speed). Automated cascading switches models if a rate limit is met.

🎭 9 Pedagogical Teaching Styles

Tailored modes: Quick Answer, Concept First, Step-by-Step, Exam-Oriented, Sports Mode (Cricket analogies), Real-Life, Story, Social Buddy, and Socratic Mode.

📚 NCERT Textbook Grounding (RAG)

Every explanation is cross-verified against official Class 9–12 textbooks, providing students with exact textbook chapter citations and clickable NCERT PDF links.

🛡️ Guardrails & Typo Fuzzy Matching

Strict defensive filters block non-math prompts, prompt injections, and database leaks, while fuzzy matching corrects student phonetic typos (e.g. "tignomatry").

📐 KaTeX Formula & SVG Diagrams

Instant rendering of LaTeX math ($$\int$$, $$\sum$$, radicals, fractions) plus real-time generation of interactive SVG coordinate graphs and geometric diagrams.

🎙️ Speech Dictation & AI Voice (TTS)

Voice question input (STT) combined with a specialized Text-to-Speech (TTS) converter that translates complex LaTeX syntax into clear spoken words.

🔐 Dual Authentication & User Isolation

Google OAuth 2.0 alongside standard email login with Bcrypt password hashing. Chat histories and pinned discussions are strictly isolated per user_id.

🛠️ Developer RAG Control Center

Admin panel enabling educators and developers to upload supplementary PDF textbooks, paste custom lecture notes, or scrape math web articles directly into vectors.

🔒 6. Security & Privacy Guarantees

Security Standards Enforced:
  • Zero Plaintext Passwords: Salted Bcrypt hashing ensures database dumps cannot expose credentials.
  • Data Isolation: Queries are restricted by WHERE user_id = :authenticated_user_id to prevent cross-account leaks.
  • SSRF Protection: RAG web scrapers reject private network targets (127.0.0.1, localhost).
  • Air-Gapped Developer Mode: Developer admin routes can be restricted to local development environments, leaving zero administrative attack surface on the live internet.
